# Delivery roadmap

1. Foundations: portable builds, shared diagnostics, schema, CI, licensing.
2. Controller sensor plane: enrollment, HMAC ingest, replay defense, storage.
3. Headless sensor core: probes, scheduler, aggregation, spool, uploader, IPC.
4. Full measurement set: scheduled speed/responsiveness and link context.
5. Desktop experience: tray, four-screen GUI, deep links, signed installers.
6. Fleet operations: profiles, alerts, quotas, charts, operator workflows.
7. Distribution and updates: six targets, channels, verified update/rollback.

Detailed normative requirements and acceptance criteria are maintained in the
cross-repository Axon Pulse implementation plan.
